# Security Workflow

- Do not put secrets, credentials, private customer data, or weaponized exploit detail in tickets.
- Identify the asset, actor, trust boundary, and realistic impact before proposing a fix.
- Prefer the smallest change that closes the boundary without weakening adjacent controls.
- Validate the security property and expected legitimate behavior.
- Record disclosure, rotation, migration, and rollback needs without exposing sensitive values.
- Escalate active compromise, data exposure, or credential leakage immediately.
