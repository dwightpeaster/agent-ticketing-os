# Release Runbook

1. Confirm release scope and target version.
2. Review open, blocked, and review tickets in scope.
3. Run the full required validation set.
4. Confirm migrations, configuration changes, and rollback steps.
5. Update user-facing installation, upgrade, and behavior notes.
6. Review the release diff for unrelated changes or sensitive data.
7. Tag, publish, or deploy only with explicit authorization.
8. Record the released version, evidence, and follow-up monitoring.
