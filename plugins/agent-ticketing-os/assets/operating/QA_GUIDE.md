# QA Guide

Convert reports into reproducible evidence before changing code.

1. Capture expected and actual behavior.
2. Identify environment, account state, data state, and frequency.
3. Reduce the report to the smallest reliable reproduction.
4. Record screenshots or logs only when they clarify the failure.
5. Create separate tickets for independent failures.

Validate the repaired workflow and one relevant neighboring path. If the environment cannot be reproduced, record the limitation and the next diagnostic action.
