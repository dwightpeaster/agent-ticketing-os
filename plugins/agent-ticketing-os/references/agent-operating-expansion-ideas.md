# Agent Operating Expansion Ideas

These ideas come from mature agent-led repository workflows: agent instructions, branch workflow, commit workflow, QA guides, review checklists, issue templates, security policy, release runbooks, implementation standards, writing standards, and repo-local skills.

## Strong Candidates For New Skills

- `$agent-ticketing-ready-check`
- `$agent-ticketing-complete`
- `$agent-ticketing-qa-intake`
- `$agent-ticketing-branch`
- `$agent-ticketing-review`
- `$agent-ticketing-decision`
- `$agent-ticketing-dead-code`
- `$agent-ticketing-release`

## Profile Features To Add

The strict operating profile can optionally create:

- `AGENTS.md`
- `CLAUDE.md`
- `docs/TICKET_STANDARDS.md`
- `docs/DEFINITION_OF_DONE.md`
- `docs/BRANCH_WORKFLOW.md`
- `docs/AGENT_COMMIT_WORKFLOW.md`
- `docs/AGENT_QA_GUIDE.md`
- `docs/REVIEW_CHECKLIST.md`
- `docs/WRITING_STANDARDS.md`
- `docs/IMPLEMENTATION_STANDARDS.md`
- `docs/DEAD_CODE_REMOVAL.md`
- `.github/pull_request_template.md`
- `.github/ISSUE_TEMPLATE/*.md`

This should be an opt-in full agent operating system mode, not the default ticket-only mode.
